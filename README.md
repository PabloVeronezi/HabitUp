# HabitUp

Programa para cadastrar e gerenciar hábitos diários.

## Objetivo

Ajudar pessoas a se manterem organizadas durante o dia, permitindo cadastrar e acompanhar hábitos de forma simples.

## Status

Em desenvolvimento.

Atualmente, a aplicação já permite:

- cadastrar hábitos dinamicamente;
- validar hábitos vazios ou compostos apenas por espaços;
- exibir feedback visual para entradas inválidas;
- normalizar o texto dos hábitos cadastrados;
- manter o foco no campo de entrada após o cadastro.

## Tecnologias

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Funcionalidades implementadas

- Estrutura semântica da página
- Layout responsivo
- Cadastro de hábitos pelo formulário
- Cadastro via botão ou tecla Enter
- Validação de entrada
- Feedback visual de erro
- Normalização do texto digitado
